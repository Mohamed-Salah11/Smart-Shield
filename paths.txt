Smart Shield FreeBSD Path Map
=============================

Project install paths
---------------------
- App code root: /usr/local/share/smart-shield
- WSGI entrypoint: /usr/local/share/smart-shield/wsgi.py
- Virtual environment (optional): /usr/local/share/smart-shield/.venv
- Main config: /usr/local/etc/smart-shield/config.json
- Environment file: /usr/local/etc/smart-shield/smart-shield.env
- rc.d service script: /usr/local/etc/rc.d/smart_shield
- Service enable flags: /etc/rc.conf (or /etc/rc.conf.d/smart_shield)

Project runtime/state paths
---------------------------
- SQLite DB: /var/db/smart-shield/data.db
- Uploads: /var/db/smart-shield/uploads/profile_pictures
- Backups: /var/db/smart-shield/backups
- Generated state/cache: /var/db/smart-shield/state
- PID/socket dir: /var/run/smart-shield
- Logs: /var/log/smart-shield/
- Crypto material: /var/db/smart-shield/crypto/

Firewall service (PF)
---------------------
- Smart Shield generated PF config: /usr/local/etc/smart-shield/pf/pf.conf.generated
- Smart Shield anchors dir: /usr/local/etc/smart-shield/pf/anchors
- Smart Shield tables dir: /usr/local/etc/smart-shield/pf/tables
- Active FreeBSD PF config: /etc/pf.conf
- Active PF anchor dir: /etc/pf.anchors/
- Last-known-good PF backup: /var/db/smart-shield/state/pf.lastgood.conf

Network interfaces + routing
----------------------------
- Interface/routing state cache: /var/db/smart-shield/state/interfaces.json
- Route state cache: /var/db/smart-shield/state/routes.json
- FreeBSD interface config source: /etc/rc.conf

DHCP services
-------------
- Smart Shield DHCPv4 generated (Kea): /usr/local/etc/smart-shield/services/kea/kea-dhcp4.conf.generated
- Smart Shield DHCPv6 generated (Kea): /usr/local/etc/smart-shield/services/kea/kea-dhcp6.conf.generated
- Smart Shield DHCP relay generated: /usr/local/etc/smart-shield/services/dhcrelay/dhcrelay.conf.generated
- Active Kea DHCPv4 config: /usr/local/etc/kea/kea-dhcp4.conf
- Active Kea DHCPv6 config: /usr/local/etc/kea/kea-dhcp6.conf
- Active ISC dhcpd config (if used instead of Kea): /usr/local/etc/dhcpd.conf
- DHCP leases/cache export: /var/db/smart-shield/state/dhcp-leases.json

DNS services
------------
- Smart Shield resolver generated (Unbound): /usr/local/etc/smart-shield/services/unbound/unbound.conf.generated
- Smart Shield forwarder generated (dnsmasq): /usr/local/etc/smart-shield/services/dns-forwarder/dnsmasq.conf.generated
- Active Unbound config: /usr/local/etc/unbound/unbound.conf
- Active dnsmasq config: /usr/local/etc/dnsmasq.conf
- DNS overrides cache/state: /var/db/smart-shield/state/dns-overrides.json

OpenVPN service
---------------
- Smart Shield server configs: /usr/local/etc/smart-shield/services/openvpn/servers/
- Smart Shield client configs: /usr/local/etc/smart-shield/services/openvpn/clients/
- Smart Shield CSO configs: /usr/local/etc/smart-shield/services/openvpn/cso/
- Active OpenVPN config dir: /usr/local/etc/openvpn/
- OpenVPN certs/keys: /var/db/smart-shield/crypto/openvpn/

IPsec service (strongSwan/swanctl)
----------------------------------
- Smart Shield swanctl generated: /usr/local/etc/smart-shield/services/ipsec/swanctl.conf.generated
- Smart Shield IPsec secrets generated: /usr/local/etc/smart-shield/services/ipsec/ipsec.secrets.generated
- Active swanctl config: /usr/local/etc/swanctl/swanctl.conf
- Active strongSwan config dir: /usr/local/etc/strongswan.d/
- Active IPsec secrets: /usr/local/etc/ipsec.secrets
- IPsec certs/keys: /var/db/smart-shield/crypto/ipsec/

L2TP service
------------
- Smart Shield L2TP generated: /usr/local/etc/smart-shield/services/l2tp/l2tp.conf.generated
- Active MPD5 config: /usr/local/etc/mpd5/mpd.conf
- Active MPD5 secrets: /usr/local/etc/mpd5/mpd.secret

NTP service
-----------
- Smart Shield NTP generated: /usr/local/etc/smart-shield/services/ntp/ntp.conf.generated
- Active FreeBSD ntpd config: /etc/ntp.conf

SNMP service
------------
- Smart Shield SNMP generated: /usr/local/etc/smart-shield/services/snmp/snmpd.conf.generated
- Active bsnmpd config: /etc/snmpd.config
- Active net-snmp config (if pkg used): /usr/local/etc/snmpd.conf

IGMP proxy service
------------------
- Smart Shield IGMP generated: /usr/local/etc/smart-shield/services/igmp-proxy/igmpproxy.conf.generated
- Active igmpproxy config: /usr/local/etc/igmpproxy.conf

UPnP/IGD/PCP service
--------------------
- Smart Shield UPnP generated: /usr/local/etc/smart-shield/services/upnp/miniupnpd.conf.generated
- Active miniupnpd config: /usr/local/etc/miniupnpd.conf

Dynamic DNS service
-------------------
- Smart Shield ddclient generated: /usr/local/etc/smart-shield/services/dynamic-dns/ddclient.conf.generated
- Active ddclient config: /usr/local/etc/ddclient.conf

Router advertisement service
----------------------------
- Smart Shield radvd generated: /usr/local/etc/smart-shield/services/radvd/radvd.conf.generated
- Active radvd config: /usr/local/etc/radvd.conf

Captive portal service
----------------------
- Smart Shield captive portal generated: /usr/local/etc/smart-shield/services/captive-portal/portal.conf.generated

Diagnostics + monitoring
------------------------
- System activity cache: /var/db/smart-shield/state/system-activity.json
- Traffic cache: /var/db/smart-shield/state/traffic.json
- Diagnostics output cache: /var/db/smart-shield/state/diagnostics
