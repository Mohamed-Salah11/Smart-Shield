General Settings

When set to "Allow all clients", any DHCP client will get an IP address within this scope/range on this interface. If set to "Allow known clients from any interface", any DHCP client with a DUID or IP address listed in a static mapping on any interface(s) will get IP address(es). If set to "Allow known clients from only this interface", only known clients from this interface, only MAC addresses listed in static mappings on this interface will get an IP address within this scope/range

This option is not compatible with failover and cannot be enabled when a Failover Peer IP address is configured.

This option may be used when a client can dual boot using different client identifiers but the same hardware (MAC) address. Note that the resulting server behavior violates the official DHCP specification.

Primary Address Pool

The specified range for this pool must not be within the range configured on any other address pool for this interface.

If additional pools of addresses are needed inside of this subnet outside the above range, they may be specified here.
