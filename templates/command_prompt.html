Appliance Console

The live appliance console is opened from the floating Console button in the top-right navbar. It appears only for superusers, and only after a superuser enables it in System → Admin Access → Console Options.

Every command typed in the console is recorded in the appliance audit log, with passwords, tokens, and private keys redacted automatically. A live session requires a recent password re-authentication plus a single-use signed WebSocket ticket — see the Manual for details.
