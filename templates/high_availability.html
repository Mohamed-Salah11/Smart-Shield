High Availability

This page allows you to configure state and configuration synchronization for setting up a firewall cluster for failover.

State Synchronization Settings (SS-Sync)

Recommended to set this to an interface other than LAN. A dedicated interface works best. An IP must be assigned to the interface on all participating sync nodes.
Custom SS host identifier (max 8 non-zero hexadecimal characters) to uniquely identify which host created a firewall state. Each node must have a different ID.
Setting this option will force SS-Sync to synchronize its state table to this IP address. The default is directed multicast.

Configuration Synchronization Settings (XMLRPC Sync)

XMLRPC sync is currently only supported over connections using the same protocol and port as this system. Do not use the Synchronize Config to IP and password option on backup cluster members!
