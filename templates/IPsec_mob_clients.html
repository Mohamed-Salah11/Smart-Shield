When enabled, the IPsec daemon will attempt to send RADIUS accounting data for mobile IPsec connections with Virtual IP addresses. Do not enable this option unless the selected RADIUS servers are online and capable of receiving RADIUS accounting data. If RADIUS accounting data is enabled and fails to send, tunnels will be disconnected.

Client Configuration (mode-cfg)

NOTE: With iPhone clients, this does not work when deployed via the iPhone configuration utility, only by manual entry.
NOTE: IPv4-mapped IPv6 addresses (ex: fd00::1.2.3.4) are not supported.
