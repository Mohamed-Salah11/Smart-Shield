NTP Server Configuration
You may need to disable NTP if Smart Shield is running in a virtual machine and the host is responsible for the clock.
Interfaces without an IP address will not be shown. Selecting no interfaces will listen on all interfaces with a wildcard. Selecting all interfaces will explicitly listen only on the interfaces/IPs specified.
NTP will only sync if a majority of the servers agree on the time. For best results you should configure between 3 and 5 servers (NTP support pages recommend at least 4 or 5), or a pool.

NTP Serial GPS Configuration
A GPS connected via a serial port may be used as a reference clock for NTP. If the GPS also supports PPS and is properly configured, and connected, that GPS may also be used as a Pulse Per Second clock reference. NOTE: A USB GPS may work, but is not recommended due to USB bus timing issues.
This option allows a predefined configuration to be selected. Select Generic if the GPS is not listed.
By default NTP will listen for all supported NMEA sentences. One or more sentences to listen for may be specified.
Fudge time 1 is used to specify the GPS PPS signal offset (default: 0.0).
Fudge time 2 is used to specify the GPS time offset (default: 0.0).
This may be used to change the GPS Clock stratum (default: 0).
Enabling this will rapidly fill the log, but is useful for tuning Fudge time 2.
This may be used to change the GPS Clock ID (default: GPS).
NTP PPS Configuration
Devices with a Pulse Per Second output such as radios that receive a time signal from DCF77 (DE), JJY (JP), MSF (GB) or WWVB (US) may be used as a PPS reference for NTP. A serial GPS may also be used, but the serial GPS driver would usually be the better option. A PPS signal only provides a reference to the change of a second, so at least one other source to number the seconds is required.
At least 3 additional time sources should be configured under Services > NTP > Settings to reliably supply the time of each PPS pulse.
Fudge time is used to specify the PPS signal offset from the actual second such as the transmission delay between the transmitter and the receiver (default: 0.0).
This may be used to change the PPS Clock stratum (default: 0).
This may be used to change the PPS Clock ID (default: PPS).
